Web Architecture Basics

Client-Server Model

The client sends requests and the server responds with resources like web pages. Your browser is the client; the host computer is the server.

DNS (Domain Name System)

Translates easy-to-remember domain names (like google.com) into numeric IP addresses computers use to find each other.

HTTP vs HTTPS

HTTP = Hypertext Transfer Protocol — plain text, unencrypted. HTTPS = Secure HTTP — data is encrypted, safer for passwords & payments.
